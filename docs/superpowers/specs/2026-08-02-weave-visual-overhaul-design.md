# 织识 v3.0 视觉门面工程（SP1）设计

- 日期：2026-08-02
- 状态：已批准（brainstorming 会话）
- 目标版本：织识 v3.0

## 背景

织识 v2.0 功能已闭环（上传→AI 提取→图谱→编辑→融合→导出），但用户反馈：
- 功能/展示/提取/交互四个维度都显单薄
- 前端界面"页面显空、图谱不够出彩、风格不统一、缺高级感"

经 brainstorming 明确方向：**多页面架构 + 页面转场 + 每页独立性格 + 动态渲染**，拒绝"单一外壳 + 固定模板"。

## 设计目标

1. 点击导航是**真正的页面跳转**，配命名转场动效，不再在单一外壳里弹对话框
2. 每个页面**独立成页且不普通**——有独特叙事、打破常规的布局、经得起放大的细节
3. 全站**动态渲染**：提取过程可视化、数据动效、滚动叙事、图谱交互动效
4. 共用一套设计令牌，但**每页一个主导色 + 独特布局性格**，整体统一又有变化

## 页面架构（v3.0）

| 路由 | 页面 | 状态 | 主导色 | 性格 |
|---|---|---|---|---|
| `/` | 首页 Landing | 重构 | 朱砂暖 | 品牌开篇、仪式感 |
| `/library` | 知识库 | 重构 | 墨青 | 信息编排、错落 |
| `/import` | 导入向导 | **新增** | 朱砂→青渐变 | 分步引导（替代各页弹窗）|
| `/workbench/:paperId` | 知识工作台 | 重构 | 暗金 | 深色沉浸、专注 |
| `/explore` | 全局探索 | 重构 | 夜紫 | 深邃开阔、漫游 |

**转场系统**：`<router-view>` 按路由 `meta.transition` 配置命名转场——淡入位移 / 缩放 / 织入，全部用 `transform/opacity`（GPU 加速），统一进出编排（错峰 80ms）。

## 里程碑 A · 设计系统 + 全局动效层 + 转场（地基）

### A1 设计令牌扩展（`styles/variables.css`）
- 每页主导色变量：`--page-home-accent` / `--page-library-accent` / `--page-workbench-accent` / `--page-explore-accent`，在页面根元素上切换
- 动效曲线分级（`--ease-out-soft` / `--ease-spring`）及时长分级
- 纸张噪点纹理 overlay（SVG 噪点 data URI）、玻璃质感细化

### A2 全局动效组件库（`src/components/motion/`）
| 组件 | 用途 |
|---|---|
| `CountUp` | 统计数字滚动（首页/知识库/工作台）|
| `SkeletonBlock` | 骨架屏加载（知识库卡片、图谱加载）|
| `RevealOnScroll` | 滚动浮现指令（首页叙事、各页 section）|
| `GlowCursor` | 全局光标光点（暗色下提升质感）|
| `SealBadge` | 印章徽记组件（品牌符号，贯穿全站）|

### A3 页面转场系统
- `router/index.js` 为每条路由加 `meta.transition`
- `App.vue` 的 `<transition>` 按 name 切换转场类型
- 统一进入/离开编排

## 里程碑 B · 首页重构（含导入向导）

- **全屏 Hero**：「织」字大标 + 升级粒子背景 + 渐变光晕
- **滚动叙事**：灵感（Why）→ 方法（How）→ 作品（进知识库），三段 `RevealOnScroll` 浮现
- **分步导入向导 `/import`**：四步（PDF → 文本 → URL → 手动），替代现有弹窗式导入
- 统计数字 `CountUp` 滚动 + 最近论文卡片流

## 里程碑 C · 知识库 + 工作台 + 探索

**知识库**：错落瀑布流卡片、分组标签色彩编码、hover 抬升+光描边、骨架屏加载
**工作台**：
- 图谱视觉升级：节点辉光、连线流动、纸张噪点底纹、环境光晕
- **提取过程"织网"动画**（前端排演）：阶段进度条 → 概念节点逐个亮起 → 连线生长，真实数据返回后无缝替换
- 图谱交互动效：布局重排过渡、编辑实时反馈
- 侧栏可折叠、工具栏微缩
**探索**：夜紫深邃背景 + 漂浮概念粒子 + 融合图谱来源着色 + ⌘K 全局搜索面板

## 技术红线

1. **提取动画前端排演**：`POST /extract` 保持同步不改，前端在等待期间播放"织网"动画，结果返回后淡入替换真实数据——不碰后端 AI 流程
2. **不破坏现有功能**：编辑/撤销重做/融合/搜索/导出全部保留，视觉重做不改数据流与 API
3. **转场与动效全用 GPU 加速属性**（transform/opacity），防抖，暗色下不闪烁

## 验收标准（每里程碑）

- **A**：任一旧页面套上新令牌与转场后，导航有动画、数字能滚动、有骨架屏，无回归
- **B**：首页为完整品牌叙事；`/import` 四步可走通并进入工作台
- **C**：四页视觉统一有变化；提取时看到"织网"动画并落到真实图谱；编辑/导出/融合/搜索正常

## 范围外（不在此 SP 内）

- 后端 AI 流式真实进度（后续单独子项目）
- 功能维度扩展（批量导入、论文分组合集、统计报表）——SP4
- 展示视角扩展（时间线、对比视图）——SP3
- 图谱交互深度（多选、筛选聚焦）——SP2

## 技术栈约束

- 前端 Vue 3 + Vite + Element Plus + D3 + Pinia，改动限于 `frontend/src/`
- 后端不改（除已完成的 DeepSeek 接入）
- 设计令牌沿用现有暗色深空体系，扩展而非推倒
