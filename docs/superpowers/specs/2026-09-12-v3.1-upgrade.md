# 织识 v3.1 竞赛级全面升级 —— 设计文档

> 2026-09-12 · 覆盖 M1–M11 十一个里程碑 · 实施记录见 git log（feat/fix/refactor 按里程碑提交）

## 背景与目标

v3.0 完成后，作品工程内核已达比赛水准（TDD、性能优化、桌面打包），但存在三类硬伤：

1. **提取管线脆弱**：AI 同步调用阻塞事件循环（提取期间服务假死）、任务状态存内存、前端轮询 + 假进度动画；
2. **能力面单一**：搜索仅概念名、无正文检索与语义召回、无统计分析、导出缺学习工具链；
3. **包装缺失**：README 停留在 v2.0 四功能形态、无 CI/Docker/LICENSE/截图。

本次升级目标：让评委在**界面、交互、架构、工程**每一层都有可讲的故事。

## 里程碑设计决策

### M1 提取管线重构
- **决策**：任务状态持久化到新表 `extract_tasks`（每论文一行，UPSERT），内存 dict 仅保留运行中去重职责 → 进程重启可恢复、失败可重试、状态可跨请求查询。
- **决策**：`AIService.extract_knowledge` 异步化，LLM 调用经 `asyncio.to_thread`；分片进度经 `on_progress` 异步回调上报（extracting 区间 0.2→0.85 按分片线性推进）。
- **SSE 端点**采用**轮询 diff 实现**（0.5s 读任务行、快照变化才推送、15s 心跳、终态自关闭）：实现简单、天然跨重启、对 SQLite 压力可忽略；客户端语义上仍是标准 SSE。
- 兼容性：`GET /extract-status` 保留并增强为轮询降级通道；响应新增字段、保留 `status` 字段，前端旧轮询逻辑不破坏。

### M2 混合检索
- **三通道**：concepts（既有 FTS5 trigram，BM25 排序）/ fulltext（新增 `papers_fts`：标题+正文）/ semantic（`concept_embeddings` 向量余弦，阈值 0.55）。
- **融合**：Reciprocal Rank Fusion（k=60），对异构通道分数量纲不敏感；概念结果可标注多通道命中（`channels` 数组），论文命中独立 kind。
- **向量存储**：float32 BLOB 存 SQLite（`pack/unpack_vector`），提取完成后异步索引（best-effort，失败不影响主流程）；提供 `POST /system/reindex-embeddings` 全量重建。
- **性能修复**：merge 建议从「请求时逐对 HTTP embedding」改为「预载落库向量余弦」——O(N²) HTTP 调用归零。
- **启动优化**：FTS 索引从无条件 rebuild 改为计数失同步才 rebuild（幽灵行注入测试覆盖）。

### M3 统计 + Anki
- PageRank 纯 Python 幂迭代实现（含 dangling 质量重分布），**节点按规范化概念名聚合**——全局视图下跨论文同名概念合并，排名反映真实枢纽度。
- Anki 导出用 genanki 生成真 .apkg（zip），牌组 ID 由 paper_id 哈希派生保证幂等；卡片 Extra 含类型/页码/证据/关联。

### M4 健壮性
- 路由按领域拆分（extract/graph/library/explore/system + upload 六 router），OpenAPI tag 分组。
- 日志：`weave` 根 logger 滚动文件（2MB×3）+ RequestID 中间件（透传 X-Request-ID、访问日志、异常堆栈落盘）。
- SSRF：scheme 白名单 + DNS 解析后拒绝私网/环回/链路本地 + 响应体 5MB 截断；**docstring 注明 DNS rebinding 理论窗口**（诚实标注边界而非假装彻底解决）。
- 接口契约：裸 dict → Pydantic 模型；DELETE/UPDATE 补 404/409；CORS 收紧 localhost 正则。

### M5–M10 前端
- **设计令牌单一来源**：`design/tokens.js`（JS）↔ 后端 `domain_constants.py`，七处组件副本收敛；D3 SVG 属性经 `cssVar()` 运行时读主题变量。
- **双主题**：`html.light` 覆盖式令牌（宣纸：暖纸底/墨字/辉光降级），EP 变量手动双套映射（不引入官方 dark css-vars，因现有 `!important` 覆写已较完整，避免大规模回归）；localStorage 持久化 + 首访跟随系统。
- **SSE composable**：EventSource 优先，断连且非终态自动降级 `getExtractStatus` 轮询；终态自停。
- **命令面板**：职责从 ExploreView 上移到 App.vue（全页面可用）；搜索走 M2 混合检索，`<mark>` 高亮先整体转义再还原标记（内容不可信前提下的安全渲染）；内置导航动作项。
- **乐观更新**：确认/驳回本地先行，构造新数组/新对象引用触发 `props.data` watch → D3 增量 join 刷新视觉，失败回滚——利用 v3.0 的增量渲染成果避免整图 reload。

### M11 包装
- 演示数据种子脚本：离线、幂等、`--force` 可重灌；内容含跨论文同名概念（知识图谱），可演示融合/重合/合并建议。
- Docker 多阶段（node 构建 → python 运行），`WEAVE_DATA_DIR=/data` 卷持久化，AI Key 环境变量注入。
- CI 双流水线：后端 ruff + pytest（覆盖率）｜前端 vitest + build。
- README 重写：功能矩阵、mermaid 架构图、双主题截图、三种运行方式、技术亮点答辩表、已知边界诚实披露。

## 测试策略

每里程碑 TDD：后端 48 → 90（新增进度持久化/SSE 流/事件循环响应性/RRF/语义召回降级/PageRank/Anki/SSRF/中间件），前端 41 → 56（SSE composable 状态机/Markdown 转义/图表几何/命令面板/主题）。全量绿为每个里程碑提交的前置条件。

## 遗留与边界（诚实清单）

- EP 按需引入（unplugin）评估后暂缓：14 个组件全量回归成本 > 包体收益，保持全量引入
- DNS rebinding 理论窗口：需自定义传输层才能闭合，本地单用户场景可接受
- 手动增删概念不重建向量索引（best-effort 设计），`reindex-embeddings` 可手动修复
- 认证体系未加（用户明确决策），CORS/SSRF/校验/日志构成安全基本盘
